# AI Agent 学习笔记
## 问题1
AI Agent是如何让大模型除文本回答外，还能执行外部操作？
AI Agent 在大模型基础上增加工具调用能力：
1. 大模型判断任务需要外部工具（读写文件、调用接口、查询数据库）。
2. 大模型输出结构化工具调用指令。
3. Agent框架解析指令，调用对应的外部函数/API。
4. 获取工具返回结果，把结果丢回大模型，继续推理生成最终答案。
大模型本身不直接操作电脑/接口，由Agent调度外部工具完成动作。

## 问题2
大模型记忆力有限，大量对话/Agent信息如何存储？
1. 短期上下文：保留最近几轮对话放在prompt里。
2. 长期记忆：存入外部数据库（MySQL/向量数据库）。
3. 向量数据库：把历史信息转为向量，当大模型需要相关历史时，做相似度检索，取出相关片段，塞进prompt，实现长期记忆检索。

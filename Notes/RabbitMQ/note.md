# RabbitMQ 学习笔记
## 问题1
除了“耗时任务延后处理”，还有什么场景项目会引入MQ（消息队列）？
1. 应用解耦：系统模块之间不直接调用，通过消息通信。例如用户注册成功后，发送消息，邮件服务、短信服务各自消费消息，主注册逻辑不需要等待短信发送完成。
2. 流量削峰：秒杀等高并发场景，瞬间大量请求写入MQ，后端消费者匀速消费，防止数据库瞬间被打垮。
3. 消息广播：一条消息可以被多个消费者消费，实现多模块同步事件通知。
4. 异步通知、可靠投递：保证消息一定能被消费，防止调用失败丢失业务事件。

## 问题2
如何使用Python发送消息、接收RabbitMQ消息？
使用 pika 库。
1. 安装 pip install pika
2. 生产者：建立连接，声明队列，发送消息。
3. 消费者：建立连接，声明队列，注册回调函数，持续监听队列，收到消息自动执行回调。

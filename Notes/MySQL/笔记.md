# MySQL 学习笔记
## 问题1
MySQL是像Excel那样以表格形式存储数据的。但是它可以轻轻松松承载什么数量级的数据？
MySQL 采用表结构存储数据。单表可以轻松支撑千万级行数据，库整体可以容纳上亿条记录；对于JotangNote笔记平台（全校师生，数十万笔记）属于很小的数据规模，完全可以胜任。

## 问题2
MySQL是怎么做到能轻松承载大量数据，并且查询、修改它们时仍然很快的？
1. 使用索引：类似书本目录，查找数据不需要全表逐行扫描，直接定位磁盘位置，大幅降低IO开销。
2. 存储引擎（InnoDB）：支持事务、行锁，修改数据时只锁定单行，并发性能更好。
3. 数据持久化在磁盘，同时有内存缓冲池（Buffer Pool），热点数据加载到内存，减少磁盘读取。
4. 优化器：自动分析SQL语句，选择最优索引和执行计划。

## 问题3
如何使用你所选择的编程语言来通过代码操作MySQL？
使用 pymysql 或者 mysql-connector-python 库。
流程：
1. 安装库 pip install pymysql
2. 建立数据库连接（地址、端口、账号、密码、库名）
3. 创建游标对象
4. 执行SQL语句（SELECT / INSERT / UPDATE / DELETE）
5. 获取结果，提交事务（写操作）
6. 关闭游标、关闭连接。

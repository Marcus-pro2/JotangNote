# JotangNote 项目说明文档（入门篇）

## 一、项目概述
JotangNote 是一个简单的笔记托管平台，支持用户注册登录、笔记的增删改查。
技术栈：Python + FastAPI + MySQL + Redis + RabbitMQ

## 二、项目结构
```
Project/
├── src/
│   ├── main.py          # FastAPI入口，启动服务
│   ├── database.py      # MySQL连接配置、建库建表
│   ├── redis_client.py # Redis连接配置
│   ├── mq.py            # RabbitMQ连接配置
│   ├── auth.py          # JWT生成验证、密码加密
│   ├── schemas.py      # Pydantic请求/响应模型
│   ├── worker.py        # MQ消费者，后台执行数据库操作
│   └── routers/
│       ├── users.py     # 用户注册、登录接口
│       └── notes.py    # 笔记增删改查接口
├── requirements.txt    # Python依赖列表
└── docs/
```

## 三、数据库设计

### users 表（用户表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT 自增主键 | 用户唯一ID |
| username | VARCHAR(50) 唯一 | 用户名 |
| password_hash | VARCHAR(255) | 加密后的密码（bcrypt） |
| created_at | TIMESTAMP | 注册时间 |

### notes 表（笔记表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT 自增主键 | 笔记唯一ID |
| user_id | INT 外键→users.id | 笔记发布者ID |
| title | VARCHAR(200) | 笔记标题 |
| content | TEXT | 笔记正文 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

## 四、核心功能说明

### 4.1 用户注册与登录
**使用流程：**
1. POST /users/register，传入用户名密码
2. 系统检查用户名是否已存在
3. 用bcrypt加密密码，存入users表
4. POST /users/login，传入用户名密码
5. 系统查库验证密码，成功则返回JWT token

**核心逻辑：**
- 密码用bcrypt加密存储，数据库里看不到明文密码
- 登录成功后返回JWT token，后续请求在Header里带token
- get_current_user依赖从token解析出当前用户名

### 4.2 笔记查询（带Redis缓存）
**使用流程：**
1. GET /notes/{note_id}，Header带token
2. 先查Redis缓存 key=note:{note_id}
3. 缓存命中直接返回
4. 缓存没命中，查MySQL
5. MySQL查到后，结果写入Redis缓存（5分钟过期）
6. MySQL没查到，缓存一个空标记（60秒），返回404

**解决的三个经典问题：**
- 缓存一致性：修改/删除笔记时，主动删除对应Redis缓存
- 缓存穿透：查询不存在的笔记时，缓存空值__NOT_EXIST__，防止恶意刷不存在的ID打挂MySQL
- 缓存击穿：当前用了简单的过期时间方案，高并发场景下可以加互斥锁

### 4.3 笔记增删改（异步，通过RabbitMQ）
**使用流程：**
1. POST /notes 新增笔记
2. 接口不直接操作数据库，而是把操作封装成JSON消息
3. 消息投递到RabbitMQ队列note_operations
4. 接口立即返回"任务已提交"
5. 后台worker.py消费者从队列取消息
6. 消费者执行真正的INSERT/UPDATE/DELETE
7. 处理成功后手动ack确认消息

**消息格式：**
```json
{
  "action": "create|update|delete",
  "data": { ...具体数据... }
}
```

**幂等性处理：**
- 修改前先查笔记是否存在，不存在就跳过
- 删除前先查笔记是否存在，不存在就跳过
- 这样即使同一条消息重复投递，也不会产生重复数据

## 五、启动方式

### 前置服务
需要先启动：MySQL（3306）、Redis（6379）、RabbitMQ（5672）

### 启动API服务
```bash
cd Project/src
python main.py
```
访问 http://127.0.0.1:8080/docs 可以看到Swagger测试页面

### 启动MQ消费者
```bash
cd Project/src
python worker.py
```

## 六、测试接口
打开 http://127.0.0.1:8080/docs ，按顺序测试：
1. POST /users/register 注册用户
2. POST /users/login 登录拿token
3. 点右上角Authorize，输入token
4. POST /notes 新增笔记
5. GET /notes/{id} 查询笔记
6. PUT /notes/{id} 修改笔记
7. DELETE /notes/{id} 删除笔记

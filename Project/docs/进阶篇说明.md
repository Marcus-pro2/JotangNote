# JotangNote 进阶篇说明文档

## 一、AI聊天接口（/chat）

### 功能
用户可以通过 /chat 接口和AI对话，AI能记住之前说过的话（会话管理）。

### 使用流程
1. POST /chat，body里传 message（你说的话）
2. 后端把历史对话+你的新消息一起发给AI
3. AI返回回复
4. 后端把回复存进会话历史，返回给用户

### 核心逻辑
- 会话存在内存里的字典：sessions[用户ID] = 消息列表
- 每条消息格式：{"role": "user/assistant/system", "content": "内容"}
- 每次请求都把完整历史发给AI，AI就有"记忆"了

## 二、Tool Use（AI自己调用函数查笔记）

### 功能
用户问"帮我看看第1篇笔记写了啥"，AI会自动调用我们写的 get_note_by_id 函数去数据库查，然后把结果总结给用户。用户看不到中间调用过程。

### 流程
1. 我们在请求里带上工具定义（TOOLS数组），告诉AI有哪些函数可以用
2. AI判断需要查笔记，返回 tool_calls 字段，说"我要调用get_note_by_id，参数note_id=1"
3. 我们的代码解析这个字段，真的去数据库执行查询
4. 把查询结果再发给AI，说"这是你要的数据"
5. AI根据数据生成最终回复，返回给用户

### 关键代码
- TOOLS数组：定义工具的名字、描述、参数格式
- get_note_by_id()：真正去数据库查笔记的函数
- tool_calls解析：判断AI是不是要调用工具，如果是就执行

## 三、前端页面

### 功能
一个简单的网页，包含：
- 登录/注册
- 笔记列表、新增笔记
- AI聊天窗口

### 访问地址
启动服务后打开 http://127.0.0.1:8080

## 四、注意事项
- 需要在 ai_config.py 里填你自己的API Key
- 默认用的是MiMo的接口地址，换成Deepseek就改OPENAI_BASE_URL
- 会话存在内存里，重启服务就丢（加分项：可以改成Redis持久化）
